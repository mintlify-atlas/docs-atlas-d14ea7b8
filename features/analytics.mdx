## Overview

Subflow's analytics feature provides comprehensive insights into your subscription spending through interactive pie charts and detailed breakdowns. Track monthly expenses, lifetime costs, and subscription distributions to make informed decisions about your recurring payments.

## Spending Calculations

### Monthly Cost Calculation

The chart shows monthly costs, automatically adjusting yearly subscriptions:

```tsx
// components/subscription/chart-dialog.tsx:177
const data = useMemo(
    () =>
        subscription.map((item) => {
            let displayPrice = item.convertedPrice;

            // Amortize yearly subscriptions to monthly
            if (
                item.paymentCycle === "yearly" &&
                !notAmortizeYearlySubscriptions
            ) {
                displayPrice = displayPrice / 12;
            }

            const monthlyPrice = Math.round(displayPrice);
            const percentage = ((monthlyPrice / monthSpend) * 100).toFixed(1);

            return {
                name: item.name,
                value: monthlyPrice,
                percentage,
                // ...
            };
        }),
    [subscription, monthSpend, notAmortizeYearlySubscriptions],
);
```

<Note>
By default, yearly subscriptions are divided by 12 to show their monthly impact. This can be disabled in user preferences.
</Note>

### Total Spend Calculation

Lifetime spending is calculated from the start date:

```tsx
// components/subscription/chart-dialog.tsx:48
const calculateMonthsFromStart = (startDate: {
    year: number;
    month: number;
    date: number;
}) => {
    const now = new Date();
    const monthDiff =
        (now.getFullYear() - startDate.year) * 12 +
        (now.getMonth() + 1 - startDate.month);
    return Math.max(1, monthDiff); // Minimum 1 month
};

// Then multiply by monthly cost
const monthsFromStart = calculateMonthsFromStart(item.startDate);
const totalSpend = monthlyPrice * monthsFromStart;
```

<Warning>
Total spend assumes consistent monthly payments. Price changes during the subscription lifetime are not reflected.
</Warning>

## Sorting and Organization

Subscriptions are automatically sorted by percentage:

```tsx
// components/subscription/chart-dialog.tsx:208
const sortedData = useMemo(
    () =>
        [...data].sort(
            (a, b) => Number(b.percentage) - Number(a.percentage),
        ),
    [data],
);
```

This ensures:
- Largest expenses appear first
- Easy identification of top spending categories
- Consistent ordering for comparison

## User Preferences

### Yearly Subscription Amortization

Users can choose how yearly subscriptions are displayed:

```tsx
// components/subscription/chart-dialog.tsx:161
const { notAmortizeYearlySubscriptions } = usePreferences();

if (item.paymentCycle === "yearly" && !notAmortizeYearlySubscriptions) {
    displayPrice = displayPrice / 12; // Show monthly equivalent
}
```

<Tabs>
  <Tab title="Amortized (Default)">
    **Effect**: Yearly subscriptions divided by 12
    
    **Use case**: Understanding monthly budget impact
    
    **Example**: $120/year → $10/month in chart
  </Tab>

  <Tab title="Not Amortized">
    **Effect**: Yearly subscriptions shown as full annual cost
    
    **Use case**: Seeing actual yearly charges
    
    **Example**: $120/year → $120 in chart (skews monthly view)
  </Tab>
</Tabs>

<Note>
When amortization is disabled, a note appears explaining that yearly subscriptions are shown as annual costs.
</Note>

## Currency Conversion

Analytics automatically convert multi-currency subscriptions:

```typescript
// Subscriptions stored in original currency
const subscription = {
    price: 9.99,
    currency: "EUR"
};

// Converted to user's preferred currency
const convertedPrice = subscription.price * exchangeRate;

// Displayed in analytics
const data = {
    value: Math.round(convertedPrice),
    currency: "USD" // User's preferred currency
};
```

<Note>
All subscriptions are converted to your preferred currency using current exchange rates for accurate comparison.
</Note>

## Best Practices

### Regular Reviews

<Tip>
Check your analytics monthly to stay aware of spending patterns and identify subscriptions you no longer use.
</Tip>

### Accurate Start Dates

<Warning>
Total spend calculations depend on accurate start dates. Review and update start dates if you migrated from another tracking system.
</Warning>

### Consider Yearly Subscriptions

When analyzing costs:
- Enable amortization to see monthly budget impact
- Disable amortization to see actual yearly charges
- Compare both views for complete understanding

### Share Insights

Use analytics to:
- Justify cost-sharing with family members
- Demonstrate savings from yearly vs. monthly plans
- Make informed decisions about subscription bundles
