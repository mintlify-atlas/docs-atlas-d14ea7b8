## Overview

Subflow's calendar tracking feature provides a visual representation of your subscription payment schedule. See all your upcoming payments at a glance, organized by date, with interactive hover cards and mobile-friendly drawers.

## Calendar View

The calendar displays your subscriptions based on their start date and payment cycle:

- **Monthly subscriptions** appear on the same date every month
- **Yearly subscriptions** appear once per year on the anniversary
- **Multiple subscriptions** on the same day are stacked with indicators

## Interactive Features

### Desktop: Hover Cards

On desktop, hovering over a calendar date with subscriptions reveals a hover card showing:

- All subscriptions due that day
- Service names and icons
- Quick actions (edit, delete)

```tsx
// components/subscription/calendar-cell.tsx:146
<HoverCard openDelay={150} closeDelay={50}>
    <HoverCardTrigger asChild>{cellContent}</HoverCardTrigger>
    <HoverCardContent className="w-fit min-w-56 overflow-hidden rounded-2xl">
        <div className="custom-scrollbar max-h-66 overflow-y-auto">
            {subscription.map((sub, index) => (
                <SubscriptionListItem
                    subscription={sub}
                    onSuccess={() => setUpdatedSubscription(!updatedSubscription)}
                />
            ))}
        </div>
    </HoverCardContent>
</HoverCard>
```

<Note>
Hover cards have a 150ms open delay to prevent accidental triggers while moving your mouse across the calendar.
</Note>

### Mobile: Swipe Drawers

On mobile devices, tapping a calendar date opens a bottom drawer with the same information:

```tsx
// components/subscription/calendar-cell.tsx:114
<Drawer open={drawerOpen} onOpenChange={setDrawerOpen}>
    <DrawerTrigger asChild>
        <div onClick={() => setDrawerOpen((prev) => !prev)}>
            {cellContent}
        </div>
    </DrawerTrigger>
    <DrawerContent className="max-h-[60vh] overflow-y-auto">
        {subscription.map((sub, index) => (
            <SubscriptionListItem
                subscription={sub}
                onSuccess={() => {
                    setUpdatedSubscription(!updatedSubscription);
                    setDrawerOpen(false);
                }}
            />
        ))}
    </DrawerContent>
</Drawer>
```

<Tip>
The drawer automatically closes after editing or deleting a subscription for a seamless experience.
</Tip>

## Calendar Data Structure

The calendar is built from a simple data model:

```typescript
// types/calendar.ts
export interface Calendar {
    date: string;        // ISO format: "2024-01-15"
    weekday: number;     // 0-6 (Sunday to Saturday)
    isCurrentMonth: boolean;
}
```

### Building the Calendar

The calendar component maps subscriptions to dates based on their payment cycle:

```typescript
// Example: Calculating payment dates
function getPaymentDates(subscription: Subscription, month: number, year: number) {
    const { startDate, paymentCycle } = subscription;
    
    if (paymentCycle === "monthly") {
        // Appears on same date every month
        return [new Date(year, month, startDate.date)];
    } else if (paymentCycle === "yearly") {
        // Only appears in anniversary month
        if (month === startDate.month - 1) {
            return [new Date(year, month, startDate.date)];
        }
        return [];
    }
}
```

## Payment Cycle Tracking

### Monthly Subscriptions

<Steps>
  <Step title="Start Date">
    The subscription appears on the same date each month based on the start date.
    
    Example: Start date of January 15 → appears on 15th of every month
  </Step>

  <Step title="Month Edge Cases">
    For dates that don't exist in all months (e.g., 31st), the subscription appears on the last day of shorter months.
  </Step>

  <Step title="Recurring Display">
    The subscription icon appears every month indefinitely until deleted.
  </Step>
</Steps>

### Yearly Subscriptions

<Steps>
  <Step title="Anniversary Date">
    The subscription appears once per year on the exact anniversary of the start date.
    
    Example: Start date of June 10, 2024 → appears only on June 10 each year
  </Step>

  <Step title="Annual Reminder">
    Only the anniversary month shows the subscription in the calendar.
  </Step>
</Steps>

## Best Practices

### Accurate Start Dates

Ensure subscription start dates match your actual billing dates:

<Warning>
If your Netflix subscription bills on the 15th but you enter the 10th, the calendar will show incorrect payment dates throughout the year.
</Warning>

### Regular Calendar Checks

<Tip>
Review your calendar weekly to stay aware of upcoming charges and avoid overdraft fees.
</Tip>

### Co-Subscription Visibility

Shared subscriptions appear in all co-subscribers' calendars:

```typescript
// Subscriptions appear for both owner and confirmed co-subscribers
const subscriptions = await Subscription.find({
    $or: [
        { userId },
        {
            coSubscribers: {
                $elemMatch: {
                    email: userEmail,
                    confirm: true, // Only confirmed co-subscribers see it
                },
            },
        },
    ],
});
```

## Performance Optimization

The calendar efficiently handles many subscriptions:

- **Lazy rendering**: Only visible month cells are fully rendered
- **Icon caching**: Service icons are loaded once and reused
- **Hover delay**: 150ms delay prevents unnecessary renders from mouse movement
- **Subscription grouping**: Subscriptions are pre-grouped by date before rendering
